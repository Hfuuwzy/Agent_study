## 1. 语言模型演进

### 1.1 N-gram模型

**核心思想**: 一个词的出现概率只与它前面的N-1个词有关（马尔可夫假设）

**Bigram示例**:
```
P(datawhale agent learns) ≈ P(datawhale) × P(agent|datawhale) × P(learns|agent)
                        ≈ 0.333 × 1.0 × 0.5 ≈ 0.167
```

**致命缺陷**:
- 数据稀疏性：未见过的词序列概率为0
- 泛化能力差：无法理解语义相似性（agent vs robot）

### 1.2 神经网络语言模型

**核心突破**: 词嵌入（Word Embedding）

**思想**:
1. 构建语义空间：语义相近的词向量距离近
2. 学习上下文到下一个词的映射

**经典示例**:
```
vector('King') - vector('Man') + vector('Woman') ≈ vector('Queen')
```

**余弦相似度**:
```
similarity(a,b) = cos(θ) = (a·b) / (|a||b|)
```

### 1.3 RNN与LSTM

**RNN核心**: 引入隐藏状态（记忆），信息在序列中传递

**长期依赖问题**: 梯度消失/爆炸

**LSTM解决**: 细胞状态 + 门控机制
- 遗忘门：丢弃旧信息
- 输入门：存入新信息
- 输出门：输出信息

## 2. Transformer架构

### 2.1 核心创新

**问题**: RNN必须顺序处理，无法并行

**解决**: 完全依赖注意力机制，实现真正的并行计算

### 2.2 Encoder-Decoder结构

```
输入 → [Encoder] → 上下文表示 → [Decoder] → 输出
          ↓              ↓
      理解任务        生成任务
```

### 2.3 关键组件

#### (1) 自注意力机制

**核心思想**: 每个词都能"看到"所有其他词，并分配注意力权重

**三个角色**:
- **Query (Q)**: 当前词在查询
- **Key (K)**: 其他词的标签
- **Value (V)**: 其他词的内容

**计算公式**:
```
Attention(Q,K,V) = softmax(QK^T / √d_k) × V
```

**直观理解**: 像开卷考试
- Q = 考题
- K = 资料索引
- V = 资料内容

#### (2) 多头注意力

**思想**: 多个"专家"从不同角度审视，捕捉不同关系

**流程**:
1. 将Q,K,V切分成h份
2. 每份独立计算注意力
3. 拼接结果，线性变换

#### (3) 前馈网络

**结构**: 两个线性层 + ReLU
```
FFN(x) = max(0, xW₁ + b₁)W₂ + b₂
```

**特点**: 先扩大(4×)再缩小，学习更丰富特征

#### (4) 残差连接与层归一化

**残差连接**: `Output = x + Sublayer(x)`
- 解决梯度消失，支持深层网络

**层归一化**: 每层的输入分布保持稳定
- 加速收敛，提高训练稳定性

#### (5) 位置编码

**问题**: 自注意力没有位置信息

**解决**: 正弦/余弦函数生成位置向量
```
PE(pos,2i) = sin(pos / 10000^(2i/d_model))
PE(pos,2i+1) = cos(pos / 10000^(2i/d_model))
```

### 2.4 Decoder-Only架构

**GPT的突破**: 只保留Decoder，抛弃Encoder

**核心思想**: 语言任务就是"预测下一个词"

**自回归生成**:
1. 输入起始文本
2. 预测下一个词
3. 添加到输入，重复

**掩码自注意力**: 阻止模型"偷看"后面的词

**优势**:
- 训练目标统一（预测下一个词）
- 结构简单，易于扩展
- 天然适合生成任务

## 3. 与大语言模型交互

### 3.1 提示工程

#### (1) 采样参数

**Temperature**: 控制随机性
- 低(0-0.3): 精准、确定（事实性任务）
- 中(0.3-0.7): 平衡、自然（日常对话）
- 高(0.7-2): 创新、发散（创意任务）

**Top-k**: 只保留概率最高的k个token
**Top-p**: 保留累积概率≥p的最小集合

**优先级**: Temperature → Top-k → Top-p

#### (2) 提示类型

**零样本(Zero-shot)**: 直接指令，无示例
**单样本(One-shot)**: 一个示例
**少样本(Few-shot)**: 多个示例

#### (3) 指令调优

**文本补全模型** → 需要示例教会它做什么
**指令调优模型** → 可以直接下达指令

#### (4) 提示技巧

**角色扮演**: 赋予模型特定角色
**上下文示例**: 展示输入输出格式
**思维链(CoT)**: "请逐步思考"，提升推理能力

### 3.2 文本分词

#### 为何需要分词

计算机只能理解数字，需要将文本转换为token序列

#### 分词策略对比

| 策略 | 优点 | 缺点 |
|------|------|------|
| 按词 | 语义完整 | 词表爆炸，OOV问题 |
| 按字符 | 词表小，无OOV | 无独立语义，效率低 |
| 子词(BPE) | 兼顾两者 | 实现复杂 |

#### BPE算法

**核心**: 贪心合并高频相邻词元对

**流程**:
1. 初始化为基本字符
2. 统计相邻词元对频率
3. 合并最高频的对
4. 重复直到词表大小达标

**示例**:
```
初始: {'h u g </w>':1, 'p u g </w>':1}
合并(u,g)→ug: {'h ug </w>':1, 'p ug </w>':1}
合并(ug,</w>)→ug</w>: {'h ug</w>':1, 'p ug</w>':1}
```
