# 第五章 基于低代码平台的智能体搭建

> 快速概览：Coze、Dify、n8n 三大低代码平台

---

## 🎯 本章核心观点

**低代码平台 ≠ 工程师的核心技能**

作为 AI Agent 工程师，我们的核心价值在于：
- ✅ **理解底层原理** - 知道 Agent 如何思考、规划、执行
- ✅ **掌握框架开发** - 能够根据需求自建系统
- ✅ **灵活运用工具** - 低代码平台只是工具之一，不是全部

---

## 📊 三大平台对比

| 维度 | Coze (扣子) | Dify | n8n |
|------|------------|------|-----|
| **开发商** | 字节跳动 | 开源社区 | 开源社区 |
| **核心定位** | 零代码 Agent 构建 | 开源 LLM 应用平台 | 工作流自动化 |
| **技术门槛** | 极低 | 中等 | 较高 |

| **部署方式** | 云端 SaaS | 本地/云端 | 本地/云端 |
| **适用人群** | 产品经理、运营、个人创作者 | 开发者、企业团队 | 自动化工程师 |

## 🔍 平台详解

### 1. Coze (扣子)

**一句话描述**：字节跳动推出的零代码 Agent 构建平台，像搭积木一样创建智能体。

**核心功能**：
- 可视化工作流编排（拖拽节点）
- 丰富的插件生态（RSS、GitHub、天气等）
- 一键发布到多平台（微信、飞书、抖音）
- 知识库、数据库、卡片系统

**优势**：
- ✅ 上手极快，无需编程基础
- ✅ 国内网络友好，生态丰富
- ✅ 发布渠道广泛

**局限性**：
- ❌ **不支持 MCP 协议**（致命缺陷）
- ❌ 黑盒系统，无法深入定制
- ❌ 复杂工作流难以维护

**对工程师的价值**：⭐⭐
- 适合：快速验证想法、制作 Demo
- 不建议：作为核心技术栈

---

### 2. Dify

**一句话描述**：开源的 LLM 应用开发平台，提供从原型到生产的全栈解决方案。

**核心功能**：
- **Agent 工作流**：可视化编排复杂 Agent 流程
- **RAG Pipeline**：知识库 + 检索增强
- **模型管理**：支持 GPT、Claude、Llama 等数百种模型
- **MCP 支持**：标准化工具调用协议
- **多模态**：文本、图片、视频生成

**优势**：
- ✅ **开源可定制**，学习价值极高
- ✅ **企业级特性**：RBAC、审计日志、加密
- ✅ **MCP 生态**：工具标准化
- ✅ **本地部署**：数据安全可控

**局限性**：
- ⚠️ 学习曲线中等
- ⚠️ 高并发性能瓶颈（Python 实现）

**对工程师的价值**：⭐⭐⭐⭐⭐
- **强烈推荐**：阅读源码学习架构设计
- **企业必备**：私有化部署经验
- **核心技能**：MCP 协议、RAG 系统、工作流编排

---

### 3. n8n

**一句话描述**：开源的工作流自动化工具，通过连接各种 SaaS 服务实现业务流程自动化。

**核心功能**：
- 400+ 预置节点（Slack、GitHub、数据库等）
- 可视化工作流设计
- Webhook、定时触发、事件驱动
- 支持嵌入 LLM 节点

**优势**：
- ✅ 连接能力强，生态丰富
- ✅ 自动化流程标准化
- ✅ 自托管，数据可控

**局限性**：
- ⚠️ **非纯 LLM 平台**，AI 是附加功能
- ⚠️ 学习曲线陡峭
- ⚠️ 复杂逻辑维护困难

**对工程师的价值**：⭐⭐
- 适合：业务流程自动化场景
- 不建议：作为 Agent 核心技能

## 💡 关键认知

### 平台关系

```
开发层次：

┌─────────────────────────────────────┐
│  Layer 3: 框架开发（造轮子）         │
│  - AutoGen、AgentScope、LangGraph   │
│  - 自建 Agent 框架                  │
├─────────────────────────────────────┤
│  Layer 2: 低代码平台（用轮子）        │
│  - Dify（推荐）：开源、可定制        │
│  - Coze：快速验证                   │
│  - n8n：流程自动化                  │
├─────────────────────────────────────┤
│  Layer 1: 基础能力                  │
│  - Python、LLM API、Prompt Engineering│
└─────────────────────────────────────┘
```

### 工程师的定位

> **我们不是"平台使用者"，而是"平台构建者"**

- ❌ 只会用 Coze 拖拽搭建 → 可替代性强
- ✅ 理解 Dify 架构 + 能自建框架 → 核心竞争力
