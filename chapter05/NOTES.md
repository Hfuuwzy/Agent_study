# Chapter 05 学习笔记

## 核心收获

本章学习了三大低代码平台：Coze、Dify、n8n。

**关键认知**：低代码平台 ≠ 工程师的核心技能

| 平台 | 特点 | 工程师价值 |
|------|------|-----------|
| Coze | 零代码、字节跳动 | ⭐⭐ 快速验证Demo |
| Dify | 开源、MCP支持 | ⭐⭐⭐⭐⭐ 强烈推荐研究源码 |
| n8n | 工作流自动化 | ⭐⭐ 业务流程自动化 |

## 关键结论

- **Dify 最值得深入学习**：开源架构、MCP协议、RAG系统
- **Coze 的致命缺陷**：不支持 MCP 协议
- **工程师定位**：不是"平台使用者"，而是"平台构建者"
