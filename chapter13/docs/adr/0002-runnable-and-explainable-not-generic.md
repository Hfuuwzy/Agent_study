# 0002 — 升级以"可运行 + 可讲明白"为准绳，不做通用化抽象

用户定位为 AI Agent 方向实习（研二），希望项目是"确实能跑、面试能讲明白"的 Agent 应用，而不是过度设计。决定：编排层保持应用级实现，只做 run 状态机、事件流、持久化、显式降级与少量评测集。

明确不做：通用化 workflow/step 抽象接口；可插拔执行器适配器（LangGraph 适配器等）；多用户认证；微服务/部署编排；独立监控平台。面试中如需回答"为什么不用 LangGraph"，用状态模型可映射的论述，而非实际引入。

理由：实习面试官看重候选人能否讲清一个真实运行的 Agent 应用；抽象层代码无法讲成"亮点"，反而占用迭代时间与可运行性预算。代价：若未来转向平台/框架方向，需重构编排层而非复用（已接受）。
