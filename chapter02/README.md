# 第二章 智能体发展史

> [!info] 学习概览
> **目标**: 理解智能体从符号主义到现代LLM的演进历程
> **重点**: 掌握"问题驱动"的范式迭代规律

---

## 1. 符号主义时代 (1950s-1980s)

### 1.1 物理符号系统假说 (1976)

**代表人物**: Allen Newell & Herbert Simon (图灵奖)

**核心论断**:
1. **充分性**: 物理符号系统能产生通用智能
2. **必要性**: 通用智能系统必然是物理符号系统

**本质**: 智能 = 符号的计算与处理

### 1.2 专家系统

**架构**:
```
用户界面 ←→ 推理机 ←→ 知识库
```

**代表系统**:
- **MYCIN** (1970s): 血液感染诊断，600条规则，置信因子处理不确定性
- **SHRDLU** (1968-1970): 积木世界，首次集成语言+规划+记忆

**推理方式**:
- 正向链: 数据驱动
- 反向链: 目标驱动

### 1.3 符号主义的局限

| 问题 | 说明 |
|------|------|
| 知识获取瓶颈 | 专家知识难以编码为规则 |
| 常识问题 | 手工编码常识几乎不可能 |
| 框架问题 | 动作后难以判断什么未变 |
| 脆弱性 | 规则外情况完全失灵 |

## 2. ELIZA: 规则驱动实践 (1966)

### 设计思想

**Joseph Weizenbaum** (MIT) 设计初衷:
> 证明机器可以**完全不理解**对话内容，却能营造"智能"假象

**意外结果**: 用户产生情感依赖（**ELIZA效应**）

### 工作机制

**四步流程**:
1. **关键词识别** - 设定优先级
2. **分解规则** - 通配符捕获 (`* my *`)
3. **代词转换** - I→you, my→your
4. **重组生成** - 随机选择模板

**示例**:
```
输入: "I am feeling sad"
匹配: "I am (.*)"
捕获: "feeling sad"
代词: "feeling sad"
输出: "How long have you been feeling sad?"
```

### 局限性

- ❌ 缺乏语义理解: "I am **not** happy" 仍匹配 "I am (.*)"
- ❌ 无上下文记忆: 每次仅基于当前输入
- ❌ 规则扩展性: 规则库爆炸，难以维护

## 3. 心智社会理论 (1986)

### Marvin Minsky 的核心思想

> "智能源于 vast diversity（巨大多样性），而非单一完美原理"

### 关键概念

**智能体 (Agent)**: 极简单的专门化心智过程
- `LINE-FINDER`: 识别线条
- `GRASP`: 负责抓握

**机构 (Agency)**: 协同工作的智能体组
- `BUILD-TOWER` → `BUILDER` → `ADD-BLOCK` → `FIND/GET/PUT`

**涌现 (Emergence)**: 复杂行为从简单局部交互中自发产生

### 对现代MAS的启发

- **去中心化控制**: 无中心节点的协调机制
- **涌现式计算**: 蚁群算法、粒子群优化
- **智能体社会性**: ACL通信语言、契约网协议

## 4. 学习范式演进

### 4.1 联结主义 (1980s)

| 符号主义 | 联结主义 |
|----------|----------|
| 自上而下 | 自下而上 |
| 显式规则 | 分布式权重 |
| 人工编码知识 | 从数据学习 |
| 逻辑推理 | 模式识别 |

**核心**: 知识分布式存储在连接权重中，通过反向传播学习调整

### 4.2 强化学习

**核心要素**:
- Agent: 决策者
- Environment: 外部环境
- State: 当前状态
- Action: 可执行动作
- Reward: 反馈信号

**学习循环**:
```
S_t → Agent → A_t → Environment → R_{t+1} + S_{t+1}
```

**代表**: AlphaGo 通过自我对弈学习，不依赖人类棋谱

**目标**: 最大化累积奖励（回报），有时需牺牲即时奖励

### 4.3 预训练范式

**两步流程**:
1. **预训练**: 海量文本上自监督学习（预测下一个词）
2. **微调**: 少量任务数据适应下游任务

**涌现能力**:
- 上下文学习: Few-shot/Zero-shot完成任务
- 思维链推理: 分步推理提升准确性

## 5. 现代智能体 (LLM驱动)

### 5.1 核心组件

```
┌─────────────────────────────────────────┐
│           感知模块 (Perception)         │
│              ↓ 观察                     │
│           规划模块 (Planning)            │
│    LLM ←→ 记忆模块 (Memory)            │
│              ↓ 工具调用                  │
│           执行模块 (Execution)          │
│              ↓ 工具箱 (Tool Use)        │
│           环境 (Environment)            │
└─────────────────────────────────────────┘
```

### 5.2 技术融合

| 流派 | 代表 | 贡献 |
|------|------|------|
| 符号主义 | SHRDLU、专家系统 | 逻辑推理框架 |
| 联结主义 | GPT、Transformer | 感知与推理能力 |
| 行为主义 | AlphaGo | 序贯决策能力 |

**现代Agent** = LLM(联结主义) + 工具调用(符号) + 交互学习(强化)

## 7. 核心启示

### 范式演进规律

**问题驱动**: 每个新范式解决上一代的痛点，同时引入新挑战

| 范式 | 解决 | 引入 |
|------|------|------|
| 符号主义 | 从无到有 | 知识获取瓶颈 |
| 联结主义 | 知识获取 → 从数据学习 | 可解释性差 |
| 现代LLM | 数据标注 → 自监督 | 幻觉、安全 |

### 对现代Agent的启示

1. 不要预设规则 → 现实太复杂
2. 学习优于编程 → 从数据获取能力
3. 涌现优于设计 → 简单组件交互产生智能
4. 记忆至关重要 → 上下文和经验积累
5. 工具扩展能力 → Agent不是万能的
